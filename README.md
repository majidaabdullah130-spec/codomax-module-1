# InkSpace — Codomax Module 1

A responsive frontend Blog Application built for Module 1 (Day 1–Day 4) using HTML, CSS and JavaScript.

## Pages
- Home
- Login
- Register
- Dashboard
- Create Blog

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Submission
Upload the complete project folder to a GitHub repository and submit the repository URL in the internship module. Then publish your LinkedIn post and submit that post URL as the LinkedIn Post Link.
